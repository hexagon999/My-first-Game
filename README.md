# Aetheria Online

A browser-first 3D MMORPG prototype.

## Phase 1 — Playable foundation

The first milestone is a local single-player prototype featuring a low-poly training area, third-person movement, basic enemy combat, XP and level progression, and responsive touch controls.

## Run locally

```bash
npm install
npm run dev
```

Open the Vite development server on port 5173. Multiplayer, accounts, and persistence are planned for later phases.
